# Donee — งานส่วนตัว กลุ่ม และรหัสเชิญเชื่อม Supabase

## ขั้นตอนที่เหลือก่อนใช้งานกับฐานข้อมูลจริง

1. เปิด `supabase/setup-all.sql` คัดลอกทั้งหมด → Supabase → SQL Editor → New query → วาง → Run
   - ไฟล์นี้รวมทั้งงานส่วนตัวและกลุ่มแล้ว ไม่ต้องรัน setup-tasks.sql / setup-groups.sql แยก
   - รันซ้ำได้ ไม่ลบตารางหรือข้อมูล แต่ปรับสิทธิ์ให้ใช้ข้อมูลของตนเอง/กลุ่มที่เป็นสมาชิก
   - ถ้าพบ error เรื่องข้อมูลสมาชิกหรือรหัสเชิญซ้ำ ให้เก็บข้อมูลไว้และแก้รายการซ้ำก่อน ห้ามลบทั้งตาราง
2. `.env.local` ใช้ค่าที่ใส่ไว้เดิม ไม่ต้องเปลี่ยนคีย์ และห้ามนำ Secret key/service_role มาใส่ในแอป
3. ถ้าแอปกำลังรัน ให้ Control+C แล้วรัน `npm run web` ใหม่
4. สมัคร/ยืนยันอีเมล/Login ด้วยบัญชีจริง

## ทำอะไรได้แล้วในโค้ด

- Email/Password signup/login/logout และกู้ session
- โหลด เพิ่ม แก้ไข ติ๊กเสร็จ และลบงานส่วนตัวจาก Supabase
- สร้างกลุ่มในฐานข้อมูล พร้อมเพิ่มผู้สร้างเป็นสมาชิกในรายการเดียวกัน (transaction)
- สร้างรหัสเชิญ 12 ตัวบนฐานข้อมูล ไม่ซ้ำกับกลุ่มอื่น ไม่ใช้รหัสตัวอย่าง CREATE อีกแล้ว
- ดู/คัดลอกรหัสกลุ่มที่ตนเป็นสมาชิก แล้วให้บัญชีอื่นกรอกเข้าร่วม
- เข้าร่วมซ้ำไม่เพิ่มสมาชิกซ้ำ
- โหลดรายชื่อสมาชิกจาก UUID จริง แม้ชื่อสมาชิกเหมือนกันก็แยกคนได้
- สมาชิกเพิ่ม แก้ไข ติ๊กเสร็จ และลบงานของกลุ่มร่วมกันได้
- สุ่มงานที่ยังไม่เสร็จให้สมาชิกจริง และบันทึก assigned_to เป็น UUID
- บันทึกผลมอบหมายทั้งชุดพร้อมกัน ถ้ามีงานผิดกลุ่ม สมาชิกไม่ถูกต้อง หรืองานเสร็จไปแล้ว จะไม่บันทึกบางส่วน
- งานกลุ่มที่ตนรับผิดชอบแสดงใน My Tasks และ Calendar ด้วย
- ข้อมูลโหลดใหม่ทุก 20 วินาที และเมื่อกลับเข้าแอป หรือกดโหลดใหม่เองได้ (ยังไม่ได้ใช้ Supabase Realtime subscriptions)
- Groups เป็นกลุ่มส่วนตัว จึงไม่มี Explore รายชื่อกลุ่ม/รหัสเชิญของคนอื่น

## วิธีทดสอบด้วยสองบัญชี

1. บัญชี A Login → Groups → Create Group
2. เปิดกลุ่ม → เชิญเพื่อน → คัดลอกรหัส
3. เปิดอีกเบราว์เซอร์/หน้าต่างส่วนตัว/อีกเครื่อง → Login บัญชี B
4. Groups → เข้าร่วมด้วยรหัส → วางรหัสของ A
5. A กดโหลดใหม่ หรือรอรอบโหลด → ต้องเห็น B ในสมาชิก
6. เพิ่ม Group Task จากบัญชี A → บัญชี B โหลดใหม่ → ต้องเห็นงานเดียวกัน
7. เลือกงาน/สมาชิก → Randomize → View in Group (เป็นปุ่มยืนยันบันทึกผล)
8. ตรวจ Supabase ตาราง tasks: group_id เป็นรหัสกลุ่ม และ assigned_to เป็น UUID ของผู้รับผิดชอบ
9. Reload เว็บ/ออกแล้วเข้าใหม่ → งาน กลุ่ม สมาชิก และผู้รับผิดชอบต้องยังอยู่

Google sign-in ยังไม่ได้ตั้งค่า ไม่มีการเก็บประวัติสุ่มแต่ละรอบ เก็บผู้รับผิดชอบปัจจุบันใน tasks เท่านั้น ไม่มีระบบออกจากกลุ่ม ลบกลุ่ม หรือบทบาทหัวหน้า/สมาชิกแยกเพิ่มเติม

## ไฟล์ที่แก้

- App.js: เปลี่ยนกลุ่มตัวอย่างทั้งหมดเป็นข้อมูลจริง ปุ่มสร้าง/เข้าร่วม/เพิ่มงาน/สุ่มเรียกฐานข้อมูล พร้อมสถานะกำลังบันทึกและข้อความ error
- lib/groups.js: RPC สร้างกลุ่ม เข้าร่วม โหลดสมาชิก และบันทึกการมอบหมาย
- lib/tasks.js: รองรับทั้งงานส่วนตัวผ่านตาราง และงานกลุ่มผ่าน RPC
- supabase/setup-groups.sql: functions และสิทธิ์ข้อมูลกลุ่ม
- supabase/setup-all.sql: ไฟล์ติดตั้งรวมที่ให้รันเพียงไฟล์เดียว
- scripts/groups-db.test.mjs: ทดสอบ SQL จริงบน PostgreSQL ในหน่วยความจำ (PGlite)
- scripts/groups-client.test.mjs / tasks.test.mjs: ทดสอบคำสั่ง client และการแปลงข้อมูล
- package.json / package-lock.json: เพิ่มตัวทดสอบฐานข้อมูลเป็น dev dependency และคำสั่ง npm test

## การเข้าถึงข้อมูล

- คนนอกกลุ่มอ่านกลุ่ม รหัสเชิญ สมาชิก หรืองานกลุ่มไม่ได้
- รายชื่อสมาชิกในกลุ่มส่งเฉพาะชื่อและ UUID ไม่ส่งอีเมลของคนอื่น
- ใช้ RPC สำหรับสร้าง/เข้าร่วมกลุ่มและแก้งานกลุ่ม เพื่อให้ server ตรวจสิทธิ์เอง
- งานส่วนตัวเห็นและแก้ได้เฉพาะเจ้าของ
- สมาชิกทุกคนในกลุ่มเพิ่ม/แก้/ติ๊ก/ลบงานกลุ่ม และสุ่มมอบหมายได้ ตามพฤติกรรมงานกลุ่มที่ใช้ร่วมกัน
- SQL เปิด RLS และเพิ่ม restrictive guards ไม่ได้ปิด RLS หรือเปิดให้ anonymous เขียนข้อมูล

## ผลตรวจ

ผ่าน 19 tests รวม SQL สร้างกลุ่ม/รหัส เชื่อมสองบัญชีชื่อซ้ำ เข้าซ้ำ รหัสผิด ป้องกันคนนอก ตรวจการมอบหมายผิดกลุ่ม และ rollback ทั้งชุด รวม lint/typecheck และสร้างเว็บผ่าน

ทดสอบ SQL และสิทธิ์กับ PostgreSQL ในหน่วยความจำ ไม่ใช่การทดสอบใช้งานสองบัญชีบนโปรเจกต์ Supabase จริงของคุณ ตรวจ endpoint จริงพบว่ายังไม่มี RPC กลุ่ม (PGRST202) จึงต้องรัน setup-all.sql ก่อน ยังไม่ได้รัน SQL ให้บนโปรเจกต์จริง เพราะเครื่องมือไม่ได้รับอนุญาตให้ควบคุม Safari และไม่มีสิทธิ์ฐานข้อมูลระดับผู้ดูแลผ่าน Publishable key
